# Task 3: UX Case Study

**Domain:** UI/UX Design  
**Internship:** CodeAlpha — Month 1

## Overview
UX case study analyzing the Zomato food-delivery app: user journey, strengths, weaknesses, and 3 proposed improvements with mockups.

## Deliverables
- `case_study.html` — editable report source
- `case_study_report.pdf` — 4-5 page submission report
- `preview.png` — visual preview

## Summary of findings
- **Strengths:** fast search, live tracking, multiple payments, reviews/photos, collections.
- **Weaknesses:** cluttered home, aggressive upselling, inconsistent filters, checkout friction, accessibility gaps, dark patterns.
- **Improvements:** (1) simplified home & smart search, (2) streamlined one-screen checkout, (3) personalized & inclusive discovery.
